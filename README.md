# Reading_Swings
This is my submission to the 2026 SMT Data Challenge from the University of Toronto

Here are all the files in this GitHub Repository:

Basic_Scoreboard_Mockup - contains an image of the scoreboard mockup used in the final paper, displaying a sample scoreboard with our graphic in the middle.

CatchProb_R - The code for our catch probability model, including how catch probability changes after mid-at-bat positional adjustments.

FlyBall_Graphic.R - The code used to create the field and player graphic that formed the basis of the GIF.

Fly_Ball_GIFs.R - The code to design the GIFs shown in this repository and in the final paper.

Reading_Swings_Final_Paper - Our final paper that was submitted to the judges of the 2026 SMT Data Challenges.

Sample GIFs - The remaining five files are selected sample GIFs we created throughout the project.
